# Past presentations

Frozen, self-contained archives of each talk as delivered. Every folder has its own
`index.html`, its own `assets/` copy **and** a `deck.pdf` static export, so an archived
deck renders and deploys independently of the current root deck — future edits to the
root can never break history.

To view one: open its `index.html` in a browser, or (once deployed) visit
`https://jolow99.github.io/ai-delegated-deliberation-slides/presentations/<folder>/`.
`deck.pdf` is the same deck flattened to one 1920×1080 page per slide (all step-through
fragments revealed) for sharing over email/Slack.
